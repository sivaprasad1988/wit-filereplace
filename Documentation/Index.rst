=================
WIT File Replace
=================

:Extension key:
   wit_filereplace

:Package name:

----

On a **Development** instance, this extension replaces every frontend image
with a static placeholder image, both FAL-processed images (content
elements, ``<f:image>``, TypoScript-generated backgrounds) and raw HTML
images (RTE bodytext, hardcoded ``<img>``/lazy-load markup, inline
``background-image`` styles). Production and Staging instances are
unaffected.
